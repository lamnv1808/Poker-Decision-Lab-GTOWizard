# V3.1 — Phase 0 diagnosis

Reproduced on `feature/v3@5b19c44`, and on production (`main`), which still runs V2. Production has **no** full-hand simulator, so the user's experience of "Play as Hero" there is the legacy scripted-scenario mode.

## Content facts (measured)

| | Count |
|---|---|
| Hero scenarios | 35 (19 MATH_VERIFIED, 16 HEURISTIC; 6-, 8- and 9-max; 34 use a 1 BB big-blind ante) |
| …with exactly one Hero decision | **29** |
| …that continue after a Hero decision | 6 |
| …with a flop defined / a river defined | 15 / 10 |
| Villain (Read the Villain) scenarios | 9 (4 MATH_VERIFIED, 5 HEURISTIC) |
| Real hands / accepted decisions (prod) | 52,483 / 78,704 |
| Full-hand simulator: decisions graded (400-hand run) | ~7% |

## Issue matrix

## Preserved (must not regress)

- CSPRNG deal stored server-side; the public config is independent of the deal.
- Only public state reaches the client; per-decision `legal` is sent only after the hand ends.
- Claim-before-record (no double scoring).
- Mixed session ownership, time limit and mode override.
- Strategy/Fundamentals separation; familiarity limits; replays and branches never recorded.
